# Nathany Silva Contabilidade

Site institucional da Nathany Silva, contadora registrada no CRC/SP em Embu das Artes – SP. Contabilidade digital para MEI, pequenas empresas, abertura de CNPJ e Imposto de Renda.

**Site no ar:** https://marcelinha01.github.io/Nathany-Silva-Contabilidade/

## Estrutura

```
├── index.html        → estrutura e textos (HTML)
├── css/style.css     → cores, fontes, layout e animações (CSS)
├── js/main.js        → simulador MEI, carrossel, animações e formulário (JavaScript)
└── assets/img/       → fotos em WebP (hero, mei, ir, abertura, empresa, cliente)
```

## Recursos

- Simulador de faturamento do MEI
- Carrossel de serviços com fotos
- Atendimento direto pelo WhatsApp: (11) 97684-5878
- Formulário de contato que abre a conversa no WhatsApp
- Layout responsivo (celular, tablet e desktop)

Site estático, sem dependências: basta abrir o `index.html` ou publicar pelo GitHub Pages.
